# 物流与签收规则

## 当前物流模式

- 当前开发环境使用 Ecom 速运模拟物流，不代表已经接入真实快递公司。
- 发货地来自商品的结构化发货地；目的地来自下单时固化的收货地址快照。
- 用户只能查询本人订单的物流，商家只能查询本店订单的物流。

## 模拟轨迹

- 模拟物流不会再根据支付后的经过时间自动推进，也不承诺固定几秒内更新。
- 发货、揽收、运输、派送、签收、异常和退回均由具备权限的店铺人员、平台管理员或经确认的 Agent 操作显式记录。
- 每次更新必须指定一个物流节点并经过店铺范围、状态机、版本和幂等校验，不能跳过运输顺序伪造状态。
- 用户页面实时读取最近一次已持久化轨迹；尚未产生下一节点时如实显示当前状态。
- 当前为本地演示物流，节点和位置仅用于验证商城流程，不代表真实承运商数据。

## 隐私与异常

- 会话列表和 AI 回答默认展示脱敏物流单号；用户在有权访问的物流详情中查看允许公开的完整信息。
- 物流异常、退回或作废必须按承运状态显示，AI 不得凭空承诺送达时间。

## 长时间未收到或没有新轨迹

- 包裹长时间停留在“已揽收”或“运输中”时，页面仍以最近一次已持久化的承运节点为准；没有更晚节点不等于已经确认丢件。
- 用户可以先从订单物流卡片核对承运商、脱敏运单号、最后更新时间和当前位置，再联系店铺核查发货与承运情况。
- 如果物流明确显示异常、退回、疑似丢失，或长时间没有新轨迹，用户可以携带对应订单和物流记录联系平台人工客服；符合条件时再从订单发起售后资格检查。
- AI 可以同时查询本人订单的实时物流和本平台已发布的处理规则，但不得自行把“运输中”改成“丢失”、承诺固定到达时间或未经用户确认自动提交售后。
