# 购物与订单规则

## 商品与价格

- 商品列表和商品详情只展示营业中店铺的在售商品。
- 商品价格、款式可售库存和购买数量以商品详情页及提交订单前的实时校验为准。
- 商品下架后，历史订单仍保留订单快照；用户从历史入口访问时会收到商品已下架提示。

## 结算与订单

- 用户必须登录并选择有效收货地址后才能提交订单。
- 当前商城默认邮寄且包邮，结算页运费显示为“包邮”。
- 创建订单会预占对应 SKU 库存；支付超时或订单取消后系统释放预占库存。
- 支付成功后订单进入待发货，商家发货后进入运输中。
- 用户确认收货后订单完成；物流签收后第七天仍未手动确认时，系统可自动确认收货。

## 订单操作

- 可用按钮由订单、支付、履约和售后状态共同决定，前端不能自行推断或绕过后端状态机。
- 已完成订单可以评价；符合售后条件的订单可以发起售后。
- 用户取消未完成订单后，系统删除业务订单并保留仅供用户再次购买使用的取消快照；商家端和超级管理端不展示“已取消订单”。
